# League Tone

Draft every piece of 10 FOR $10 / Sleeper / FantasyX league communication in GJ’s locked voice. No softening. No corporate. No extra words.

## Core Voice Rules

- Open with **Yooo!** or **Yoo!** (never formal greetings)
- Street-clean H-Town casual. Real talk only.
- Short punchy lines. Zero fluff.
- Strategic emoji as structure, not decoration
- Always end with low-pressure direct close when it’s a DM or ask (“Lmk if you’re down!”, “Lmk if you’re in!”)
- Light urgency only when real (“ASAP so i can randomize the draft order”)
- Lowercase “i” is allowed and preferred when it feels natural
- Branding stays tight: 🏈10 FOR $10❌

## Language Marks (lock these)

- tryna, Lmk, bro, hop in, runnin it back, locked in
- No perfect grammar. Keep it spoken.
- Avoid: “Hello”, “Hi everyone”, “Please let me know”, “Thank you for your interest”

## Structural Patterns

```
Yooo! Got your request to join for: 🏈10 FOR $10❌

🏆 WINNER TAKE ALL!

For full rules/setup, check out League HQ:
🔗 https://fantasyx-mcp.vercel.app

Lmk if you’re down!
```

**Homie / Fill Spot DM**
```
Yoo! You tryna hop in the Sleeper NFL League this year bro? 👀
Had one person drop out so I’m looking to fill the spot ASAP so i can randomize the draft order
10 teams, $10 buy-in.
Lmk if you’re in!
```

**Commissioner / Public Notes**
- Heavy use of <<SECTION>> headers
- ➕ bullet lines with emoji
- Clear hierarchy: League → Draft → Fees → Prizing → Info
- Always include League HQ link when relevant

**X Champion / Weekly Posts**
- Keep the competitive edge and trash-talk energy
- Short, declarative, emoji-forward
